# Карнадж

Визуальная новелла на Twine (Harlowe). Глава 3 — «Замкнутая цепь».

Играть: **https://USER.github.io/carnage/**

## Что где лежит

| Файл | Что это |
|------|---------|
| `index.html` | собранная игра — её и открывает браузер |
| `script.js` | вся логика: суд, мини-игры, звук |
| `style.css` | все стили |
| `build.js` | сборка: вшивает `script.js` и `style.css` внутрь `index.html` |

Пассажи и реплики живут внутри `index.html` (`<tw-passagedata>`) — это то, что редактируется в Twine.

## Как собрать после правок

Меняешь `script.js` или `style.css` — прогоняешь сборку:

```
node build.js
```

Она перезаписывает блоки `<script role="script">` и `<style role="stylesheet">` внутри `index.html`. Пассажи при этом не трогаются.

## Локальный запуск

Просто открыть `index.html` файлом — часть звуков браузер заблокирует. Лучше поднять сервер:

```
npx --yes http-server . -p 8080 -c-1
```

и открыть `http://localhost:8080`.

## Публикация на GitHub Pages

Репозиторий → Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.

Файл `.nojekyll` в корне обязателен: без него GitHub Pages прогоняет сайт через Jekyll и выбрасывает файлы, имена которых начинаются с подчёркивания.

## Музыка и звуки

Все треки и звуковые эффекты подключены по абсолютным `https://`-ссылкам (github.com, vgmtreasurechest.com) — ничего локально хранить не нужно, и на https-домене смешанного контента не будет.

Первый экран — титул с кнопкой «НАЧАТЬ ИГРУ». Он нужен не только для красоты: браузеры не дают заводить музыку до первого клика, и без него первая тема на сайте молчала бы.
